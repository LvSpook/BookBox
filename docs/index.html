A toolbox for the bookmarks you already saved

BookBox opens on your library instead of an empty search box. Search titles, addresses, tags, notes and real page text in one place, then sort, tag, dedupe or clean up - seeing every change before it happens and nothing leaving your machine.

01

Install

BookBox isn't on the Chrome Web Store yet, so you load it from the source. This takes about a minute and only needs doing once per browser profile.

Clone (gets updates)

  • 01Clone the repo somewhere permanent.
  • 02Open chrome://extensions.
  • 03Turn on Developer mode.
  • 04Click Load unpacked and pick the public folder.
git clone https://github.com/LvSpook/BookBox.git

Download a ZIP (no Git)

  • 01On the repo page, click Code → Download ZIP.
  • 02Unzip it somewhere permanent.
  • 03Open your browser's extensions page and enable Developer mode.
  • 04Load unpacked → select the public folder.
//
Load public, not the repo root.

The manifest lives inside public/, so the repo layout mirrors the extension exactly. Pin the icon from the puzzle-piece menu; your library fills in immediately because bookmarks are read from the browser.

03

Sorting with proof

Sorting is the part most bookmark tools get wrong. BookBox proposes a plan and shows every move before it touches anything, so you can untick the ones you disagree with.

Smart Local

  • 01Reads real page content and proposes a two-level folder plan.
  • 02Works with no account, no key and no network.
  • 03Every suggestion carries a confidence and a reason.

Rules always win

  • 01Pin a site to a folder once and it stays there.
  • 02Rules beat both local and AI sorting, every time.
  • 03Turn a plain sentence into a rule with AI, or write it by hand.
04

Optional AI

AI is opt-in and stays hidden until you paste a free key. With no key, local sorting, local summaries and local answers all still work.

Ten extras, per feature

  • 01AI sorting, answers with quoted passages and follow-ups.
  • 02Per-page summaries and tag suggestions from your own vocabulary.
  • 03Duplicate-tag cleanup with a diff, and a near-duplicate tie-breaker.
  • 04Folder renaming, a plain-language reason for stale saves.
  • 05Tag-and-file on save, and turning a sentence into a rule.

Providers

  • 01Google Gemini, Groq or OpenRouter - all have free tiers.
  • 02Your key stays on your machine and is never synced.
  • 03Meaning search needs embeddings, so it appears only on Gemini.
05

Privacy

Never

  • 01No analytics or telemetry.
  • 02No ads inside the extension.
  • 03No account, no server, no selling or sharing data.
  • 04No reading pages you haven't chosen to save or index.

Leaves your browser only when

  • 01You add an AI key and ask it to sort, summarise or answer.
  • 02A dead-link check requests addresses you already saved.
  • 03You turn on cross-device sync - settings and tag names only.

The full policy is in privacy.html.
