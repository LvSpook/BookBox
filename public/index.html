BookBox

Your bookmarks, sorted.

A bookmark toolbox that opens on your library. Search everything you've saved — titles, page text, notes and tags — then sort, tag, dedupe, or clean up from the same place. All local and free.

23 demo bookmarks, including deliberate duplicates, dead links, and a moved page.

Install in Chrome, Edge, or Brave

  1. Download this project's ZIP and unzip it on your computer.
  2. Open chrome://extensions (or edge://extensions).
  3. Turn on Developer mode in the top-right corner.
  4. Click Load unpacked and select the public folder inside the unzipped folder.

Free AI sorting is optional. Smart Local works with no account. To use AI sorting, paste a free key from Google AI Studio, Groq, or OpenRouter in Settings — it stays on your machine.

Daily shortcuts: right-click any page → Save this page to BookBox, or type bb css grid in the address bar to search your library.

What's inside

  • Browse first — search, filters, and your library as the home screen.
  • Rules — always file a site in the same folder, no AI needed.
  • Confidence — every suggestion shows why it was chosen, and how sure it is.
  • Merge duplicates — keep one copy, carry over tags and notes.
  • 30-day trash — nothing is deleted instantly; restore in one click.
  • Undo history — the last 10 actions, replayable.
  • Bot-wall aware link checks — 403/429 sites are kept, not deleted.
  • Smart collections — live saved searches that update themselves.
  • Command palette — Ctrl/Cmd+K to jump anywhere.
  • Import & export — HTML, JSON, Markdown, CSV.
